About This Project

Tritiya was developed as my academy final project in machine learning and full-stack development. The brief required a complete, end-to-end data analytics system — from raw data processing to a deployed web interface.

I chose credit card fraud detection because of its real-world impact and the genuine technical challenge posed by extreme class imbalance (only 0.17 % of transactions are fraudulent). Solving this required going beyond accuracy as a metric and applying techniques like SMOTE, RobustScaler, and precision-recall optimisation.

The full-stack component gave me the opportunity to wrap the Python ML pipeline in a professional Flask REST API and build a polished dashboard UI — skills that are directly transferable to production engineering roles.

Key Learnings

  • ▸ Handling imbalanced datasets in a production ML context using SMOTE
  • ▸ Building and exposing a scikit-learn model via a Flask REST API
  • ▸ Asynchronous UI updates with Fetch and dynamic DOM manipulation
  • ▸ Storing predictions in MySQL for audit-trail purposes
